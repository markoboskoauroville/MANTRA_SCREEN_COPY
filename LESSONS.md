# LESSONS: Screen Copy (Mantra)

- 13.11.2026 scrcpy 4.x changed its wire format: video has session packets (bit 7) with the size, no width/height after the codec id; every media packet has a 12-byte header. The documentation (doc/develop.md) does not list the control message layouts: they are in app/tests/test_control_msg_serialize.c.
- The forward-tunnel dummy byte arrives right after the first accept; the device name and codec id only after all three sockets are connected. Reading them before connecting audio and control deadlocks.
- GitHub's private-repository minutes were blocked ("recent account payments have failed"): the repository is public by rule (building-repos-public.md), after the three secret checks.
- Mac microphone to the phone's WhatsApp call: see the section in the session report; Android does not mix another app's playback into a call's uplink, and the Mac cannot be a USB audio gadget. Real options: hardware (USB-C audio adapter with a cable from the Mac's output), WhatsApp Desktop on the Mac, or an emulator with the host microphone.
- 14.11.2026 "No route to host" from `adb connect` to a LAN phone that answers `nc` = macOS Local Network privacy on the adb SERVER process, which carries the permission of whichever app started it first. Proof: a second server from the terminal (`ANDROID_ADB_SERVER_PORT=5038 adb connect …`) connects at once. Fix without killing the shared server: a relay on 127.0.0.1 inside an app that has the permission.
- 14.11.2026 Rotation that "comes back": the second press of an impatient user undid the first (the toggle used the last wish and the readback was taken too early). Hold presses until the picture turned. `cmd window fixed-to-user-rotation -d 0 enabled` makes the display keep the user rotation even when the app in front asks for portrait.
- 14.11.2026 v22: the phone reaches the Mac through `adb reverse`, which is per adb device serial; the reverse must be applied again after every reconnect (it dies with the adb connection) and removed on quit. A client that closes is noticed by a blocking recv returning 0; a failed send shuts the socket down so the same path cleans up. The microphone prompt is keyed to the app's signature: after install re-sign with "Mantra Apps" so the permission survives updates.
